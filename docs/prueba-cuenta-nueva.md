# Probar Lirio como un amigo (otra cuenta de Windows en tu PC)

Una cuenta nueva de Windows es como un PC limpio: no ve tus bots, tus llaves ni tu configuración. Gratis.

## 1. Crear la cuenta (lo haces tú, 2 minutos)
1. Inicio → **Configuración** → **Cuentas** → **Otros usuarios** → **Agregar cuenta**.
2. «No tengo los datos de inicio de sesión de esta persona» → «Agregar un usuario sin cuenta Microsoft».
3. Nombre, por ejemplo `PruebaLirio`, y una contraseña cualquiera.

## 2. Instalar Lirio en esa cuenta
1. Cierra sesión (o «Cambiar de usuario») y entra en `PruebaLirio`.
2. Abre el navegador y descarga el instalador desde
   la página **Releases** del repositorio de Lirio en GitHub → `Lirio_0.2.0_x64-setup.exe`.
3. Ábrelo. Windows mostrará el aviso azul de SmartScreen (normal: no compramos certificado):
   «Más información» → «Ejecutar de todas formas».
4. Lirio se abre con el asistente: sigue los pasos como lo haría un amigo.
   - Los bots ocupan varios GB (el editor, unos 3 GB de librerías): tarda un rato.
   - Elige «Modo automático» si no quieres instalar nada más.

## 3. Qué mirar
- Que el asistente termine y los bots aparezcan en Lirio con su estado.
- «Diagnóstico» en cada bot.
- Configuración → «Buscar actualizaciones» (debe decir que tienes la última).
- Si algo falla: Configuración → «Enviar idea» con el resumen de uso marcado, o cuéntamelo con una captura.

## 4. Al terminar
Puedes borrar la cuenta en Configuración → Cuentas → Otros usuarios → `PruebaLirio` → Quitar
(se borran también sus archivos y los GB de los bots).
